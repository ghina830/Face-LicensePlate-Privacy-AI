# Face-LicensePlate-Privacy-AI
AI system for detecting and blurring sensitive data (faces &amp; plates) using HOG and VGG16 to comply with GDPR privacy standards.
# 🛡️ Privacy-Preserving Detection (Faces & License Plates)

## 📝 Project Overview
This project implements an AI-driven solution for **privacy protection** in images and videos. By detecting sensitive personal data like human faces and vehicle license plates, the system can automate the process of blurring or anonymizing data to comply with **GDPR (General Data Protection Regulation)** policies.

## 🚀 Technical Architecture
The system utilizes a hybrid approach for high accuracy:
* **Detection:** Using **HOG (Histogram of Oriented Gradients)** detectors for robust object localization.
* **Recognition/Classification:** Leveraging **VGG16** (Deep Learning architecture) for refined feature extraction.
* **Processing:** **OpenCV** and **imutils** for real-time image manipulation.

## 🛠️ Tech Stack
* **Language:** Python
* **Frameworks:** PyTorch, Keras
* **Libraries:** OpenCV, NumPy, imutils

## 📂 Key Features
* High-accuracy detection of license plates in various lighting conditions.
* Real-time face detection for identity protection.
* Scalable architecture for integration into surveillance systems.
